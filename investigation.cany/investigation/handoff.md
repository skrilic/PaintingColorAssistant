# Handoff

State: first version built and passing rebuild_check (build, screenshot, self-test 10/10 steps). Rust + macroquad in app/; miniquad is vendored in app/vendor/miniquad with a patch (env MINIQUAD_NO_ACTIVATE) so --screenshot/--self-test do not steal focus on macOS. Modules: colour.rs (Lab), km.rs (two-constant Kubelka-Munk per RGB channel; watercolor = layer over paper with water dilution, acrylic/oil = R_inf with white), imgproc.rs (value levels, k-means colour levels, procedural sample landscape), grid.rs (thirds/Fibonacci/grid), ui.rs (own immediate-mode widgets, rect ids for the self-test), app.rs + app/painting_view.rs + app/palettes_view.rs, selftest.rs. Palettes autosave to config dir palettes.json (not in test/screenshot modes). Extra flag --palettes opens the Palettes screen. Open unknowns: Crimson pigment code (used PR206), accuracy of estimated pigment colours/KM constants. Ideas next: spectral KM for more accurate mixes, glazing (layering transparent paints), export recipe sheet, save/restore last picture.
